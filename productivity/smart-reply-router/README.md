# smart-reply-router — отвечать на всё, платить LLM за малое

> Jev решает, в какую корзину попадает каждое сообщение. Шаблоны отвечают на известные вопросы. LLM пишет черновики только для остатка. Ничего рискованного не уходит без вас.

## Правила

| Правило | Чем обеспечено |
|---|---|
| Каждое сообщение сортируется одним пакетом Jev (намерение, запись FAQ, срочность, спам, нужен ли человек) | `references/triage-batch.md` |
| Порядок: спам → красные линии → нужен человек → критическая срочность → FAQ → LLM | `reply_route_planner.py` |
| Возвраты, юридические вопросы, жалобы, личное всегда идут человеку — даже при вероятности 35% | `reply_route_planner.py` |
| Режим `draft`, пока пользователь явно не включил `auto` | `reply_route_planner.py` — политика по умолчанию |
| Автоматически отправляются только шаблоны из базы; текст LLM — всегда черновик | `reply_route_planner.py` |
| Ключи — только в окружении / секретах | антипаттерны в `SKILL.md` |

## Быстрый старт

```bash
python skills/smart-reply-router/scripts/reply_route_planner.py --sample
```

Или скажите **«настрой автоответы для ящика поддержки»** или **«ответь на сегодняшние вопросы в Telegram»**.

## Что внутри

| Путь | Назначение |
|---|---|
| `skills/smart-reply-router/SKILL.md` | Режимы настройки, удешевления и работы по расписанию; таблица маршрутов; особенности каналов |
| `skills/smart-reply-router/references/triage-batch.md` | Готовый запрос сортировки Jev и формат входа планировщика |
| `skills/smart-reply-router/references/routing-policy.md` | Поля политики, порядок правил, почему такие значения по умолчанию |
| `skills/smart-reply-router/scripts/reply_route_planner.py` | Отсортированные сообщения → маршруты, флаги отправки, сколько вызовов LLM не понадобилось. Без сети |

Работает вместе с плагинами `jev`, `faq-knowledge-base` и `telegram-bot`.
